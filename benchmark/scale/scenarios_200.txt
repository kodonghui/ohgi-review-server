## 제20장 예약과 대기 변경
테라스 예약의 우천 전환|테라스 예약은 방문 90분 전까지 앱 예약 상세에서 실내 전환을 요청할 수 있다. 좌석 유형을 바꾸면 이전 요청 시간이 화면에 남는다.|예보가 변경된 뒤 직원이 먼저 연락한 예약은 90분이 지나도 대안을 안내할 수 있다. 실내 빈자리가 없으면 테라스 유지 또는 취소를 선택한다.|실내 좌석이 확정됐는지는 예약 상세에 새 좌석 유형과 확정 시각이 함께 표시된 뒤 확인한다. 요청 알림만 받은 예약의 배정 상태는 직원이 조회한다.
창가 요청의 대기 합류|창가를 희망하는 손님은 입구 단말기의 메모에 창가를 표시하고 일반 대기표를 받는다. 같은 대기 그룹은 한 번호로 합류한다.|창가 좌석을 기다리는 동안 일반 좌석 호출을 넘기면 기존 대기 번호의 일반 좌석 우선권이 사라진다. 휠체어 동선 요청은 접근성 규정을 적용한다.|창가 배정은 직원이 번호와 착석 테이블을 함께 표시할 때 확정한다. 대기 화면에 예상 시간이 보여도 실제로 자리가 비었는지는 직원이 확인한다.
성수기 방문 인원 축소|성수기 예약의 인원을 줄이려면 방문 3시간 전까지 예약 링크에서 새 인원 수를 제출한다. 예약 대표자와 시간은 유지된다.|인원 감소로 룸 최소 인원에 못 미치면 직원이 일반석 선택지를 먼저 안내한다. 예약금의 반환 여부는 룸 약관에 따라 따로 확인한다.|인원 변경이 끝난 영수증에는 전후 인원과 수정 시각이 기록된다. 문자에 예약 번호만 남아 있으면 수정 완료를 확인할 수 없다.
영유아 동반 인원 추가|유아 의자가 필요한 예약은 성인 인원과 유아 인원을 각각 적어 방문 당일 오전 11시까지 앱 문의로 제출한다. 유아를 성인 좌석 수에 더해 접수한다.|만석 안내 뒤에는 유아 의자만 따로 지나가는 통로에 놓을 수 없다. 기존 예약을 유지하거나 직원이 알려 준 다른 시간으로 변경한다.|유아 의자 준비는 예약 담당 직원이 현장 수량을 확인해 앱에 기록한다. 예약 상세에 유아 인원이 증가한 사실은 의자 배치 확인과 별도다.
예약자 대표 교체|단체방의 예약 대표를 바꾸려면 기존 대표가 방문 전날 오후 6시까지 새 대표에게 앱 이전 링크를 보낸다. 방문 시간과 단체 메뉴는 그대로 승계된다.|기존 대표가 링크를 보낼 수 없을 때는 예약 번호와 계약 담당자 연락 이력이 있어야 직원이 교체 요청을 받는다. 일반 인원 수정 화면으로는 대표를 바꿀 수 없다.|새 대표가 링크를 수락하고 앱에 새 이름이 표시되면 이전이 완료된다. 이전 링크 발송만으로 예약자 변경 여부를 공개 답글에서 확정하지 않는다.
시식 예약 중복 접수|한 사람이 같은 시식 회차에 두 번 접수한 경우 앱 문의에 남길 예약 번호 하나와 취소할 예약 번호 하나를 적는다. 취소 요청 전에는 두 예약이 모두 보인다.|서로 다른 회차에 접수한 경우 중복 정리 대상에 해당하지 않는다. 두 예약에 서로 다른 사람이 참석할 예정이면 대표자 교체 규정을 따른다.|중복 취소는 해당 예약 번호가 취소로 표시되고 남길 번호가 유지된 것을 함께 확인한다. 메일 발송 시간이 빠른 쪽을 자동으로 남기지 않는다.
개별 룸 입실 지연|개별 룸 예약이 10분 이상 늦어질 예정이면 앱 예약 상세에 예상 도착 시각을 남긴다. 예상 시각은 전체 사용 종료 시각을 연장하지 않는다.|지연 안내가 있어도 룸 회차 사이에 필요한 정리 시간이 줄어들지 않는다. 예약 확정 시간을 넘기는 이용은 다음 예약이 없는 날 직원 확인 후 안내한다.|룸 이용 시간이 조정됐다면 예약 상세에 조정된 시작·종료 시각이 모두 표시된다. 도착이 접수됐다는 문자만으로 연장 승인을 확정할 수 없다.
입구 단말기 점검 중 대기 접수|입구 단말기 화면에 점검 안내가 보이면 직원이 현재 팀 인원과 도착 분을 종이 대기표에 적는다. 같은 번호는 전자 대기표로 옮긴 뒤 유지한다.|단말기가 복구되기 전에 앱을 따로 새로 접수하면 종이 대기표 번호를 직원에게 먼저 알린다. 단말기 장애 시간의 호출은 복구 뒤 한 번 더 한다.|전환을 담당한 직원은 종이 번호와 전자 번호를 대조해 중복을 막는다. 방문 전에 생성한 원격 접수의 실제 순번은 현장 직원에게 확인한다.
호출 소리 안내의 대체|매장 호출을 듣기 어려운 손님은 대기표를 받을 때 화면 번호 표시를 요청할 수 있다. 직원은 첫 호출과 두 번째 호출을 화면에 각각 표시한다.|휴대전화 문자 수신이 늦은 때에는 입구 화면의 호출 시간이 기준이다. 화면과 문자가 다르면 직원이 대기 기록을 대조한다.|호출이 누락됐는지는 화면 기록과 대기 번호의 이력을 확인한 담당 직원만 판단한다. 문자 발송 상태만으로 순번을 복구하지 않는다.
낮 시간 빠른 회전석|점심 빠른 회전석은 평일 11시 30분부터 두 명 이하의 팀이 현장에서만 신청할 수 있다. 메뉴를 먼저 정한 팀의 주문표를 좌석에 전달한다.|유아 의자나 이동 보조 공간이 필요한 경우 회전석 대신 일반 대기표를 발급한다. 빠른 회전석은 예약권과 결합할 수 없다.|회전석 확정 기록에는 좌석과 예상 착석 시간이 함께 표시된다. 신청 시간만으로 먼저 착석했다고 안내하지 않는다.
스탠딩 대기 해제|스탠딩 대기에서 빠지려면 다음 호출 전에 대기표의 취소 버튼을 누른다. 휴대전화가 없으면 입구에서 종이 번호를 반납한다.|일행 한 명만 떠난 경우 전체 취소를 누르기 전에 입구 직원에게 남은 인원을 전달한다. 최소 접수 인원을 유지하면 새 번호 발급을 피할 수 있다.|취소가 완료된 대기표에는 종료 사유가 표시된다. 호출 화면에서 사라진 번호는 배정과 자진 취소를 구별해 확인한다.
바우처 예약의 시간 변경|제휴 바우처 예약 시간을 바꾸려면 전날 오후 4시까지 원래 제휴 예약 페이지에서 변경을 신청한다. 매장 앱은 좌석 현황을 보여 준다.|바우처 적용 회차를 벗어나는 시간은 제휴사 동의가 있어야 변경한다. 바우처 유효기간이 넘은 경우 일반 예약으로 새로 접수한다.|변경 완료는 제휴 예약 번호와 매장 시간표의 반영 상태를 모두 확인한다. 제휴 문자만 받은 건은 직원이 앱 반영을 확인한다.
폭염 시 야외 대기 전환|폭염 안내를 게시한 날에는 야외 대기팀이 입구에서 실내 알림으로 전환할 수 있다. 원래 대기 번호와 인원은 유지한다.|실내 대기 공간이 찼으면 직원이 그늘 위치나 근처 실내 대기 구역을 안내한다. 다른 구역에서도 번호 호출 횟수는 같다.|전환 신청을 받으면 직원이 기존 대기표에 실내 표시를 남긴다. 실내 알림이 오지 않았을 때의 완료 상태는 이 표시로 확인한다.
단체 한 팀의 지연 합류|단체 대표는 예약 시간에 먼저 도착한 사람 수와 지연 인원을 카운터에 신고한다. 팀 주문은 대표가 합류 예정 시각을 남긴 뒤 진행할 수 있다.|지연 인원을 다른 테이블에 따로 앉히려면 사업장의 일반 대기 순서를 적용한다. 기존 예약에 한 번 더 좌석을 보장하지 않는다.|직원은 착석지에 합류가 확인된 인원을 표시한다. 대표의 예상 시각만 보면 실제로 도착한 사람 수를 알 수 없다.
별실 장식 사용 사전 신청|별실 장식을 가져오려면 방문 이틀 전 오후 5시까지 예약 상세에 장식 크기와 부착 위치를 보낸다. 매장 담당자는 준비·정리 시간을 확인한다.|유리 벽과 소방 표지 주변에 테이프를 붙일 수 없다. 손님이 직접 가져온 장식의 보관은 별도 신청이 필요하다.|허용된 부착 위치는 직원 확인이 끝난 뒤 예약 상세에 표시한다. 사진만 전송된 상태에서는 장식 사용을 확정하지 않는다.

## 제21장 포장과 픽업 인계
차량 픽업 구역 대리 수령|차량 픽업 주문을 대리로 받는 사람은 지정 구역에 도착해 주문번호 뒤 네 자리와 차량 끝 두 자리를 앱 픽업 화면에 입력한다. 매장 안 포장 수령은 제69조를 적용한다.|번호가 맞아도 앱의 차량 등록 값이 다르면 카운터로 이동해 기존 주문자에게 전환 승인을 받는다. 일반 배달 기사 앱에는 차량 픽업 인증 정보를 입력하지 않는다.|차량 인계 완료는 직원이 앱에 인계 버튼을 누르고 픽업 영수증에 시간이 표시된 뒤 확인한다. 차량이 도착한 사실만으로 대리인이 음식까지 받았다고 확정하지 않는다.
픽업 알림 소리 설정|픽업 준비 알림은 주문 상세의 종 모양 메뉴에서 진동과 음성 중 하나를 고를 수 있다. 설정은 현재 주문에 먼저 적용된다.|매장 외부에서 음성 안내가 들리지 않으면 화면 번호 표시를 확인한다. 비상 안내 방송 중에는 음성 알림보다 화면이 먼저 갱신된다.|설정 변경은 저장 시간이 표시될 때 반영한다. 알림이 실제 도착했는지는 기기 기록과 주문 발송 이력을 확인한다.
보냉박스 반납 포장 수령|보냉박스 회수와 새 포장 수령을 동시에 신청한 손님은 주문번호와 회수 예약 번호를 오른쪽 포장 창구에 제시한다. 예약당 박스는 최대 두 개를 받는다.|박스가 젖었거나 뚜껑이 빠진 경우 일반 포장 제품 인계는 진행하고 박스 회수만 직원 검토로 보낸다. 할인은 박스 회수 판정과 연결한다.|회수 영수증에 박스 수량이 올라온 뒤 보증금 반환을 확인할 수 있다. 새 포장 주문을 수령한 시각은 기존 박스의 회수 확인에 쓰지 않는다.
포장 주문 두 건의 합류|한 사람이 서로 다른 두 주문을 한 번에 가져가려면 포장 창구에 주문번호 두 개와 수령 이름을 각각 제시한다. 준비 완료가 된 건부터 받을 수 있다.|일부 주문만 늦는 경우 일단 수령한 음식은 대기 진열대에 다시 놓지 않는다. 추후 수령 시간을 바꾸려면 늦는 주문의 상세에서 요청한다.|묶음 인계 영수증에 포함된 번호를 주문별로 확인할 수 있다. 두 주문 중 하나의 영수증만으로 나머지 인계를 확정하지 않는다.
성인메뉴 포함 포장 대리|성인 확인이 필요한 메뉴가 포함된 포장은 수령자가 창구에서 나이 확인 절차를 마친 뒤 받는다. 일반 포장의 연락처 확인 조건도 함께 적용한다.|인증을 끝내지 못한 수령자에게는 해당 메뉴를 따로 보관한다. 다른 메뉴 수령은 주문자가 분리 인계를 선택했을 때 진행한다.|확인 상태는 직원이 주문기록에서 해당 메뉴의 인계 결과를 확인한다. 공개 답글에 개인의 신분증 정보나 번호는 적지 않는다.
배달에서 포장으로 채널 전환|앱에서 배달을 포장으로 바꾸려면 기사에게 주문이 전달되기 전에 주문 상세의 전환 신청을 사용한다. 주소 입력 값은 포장 영수증에 인쇄하지 않는다.|기사 인계 이후에는 배달에서 포장으로 바꾸려면 직원이 기사 회수 가능 여부를 먼저 확인한다. 포장 할인 적용은 채널 변경과 함께 조회한다.|변경 완료 화면에는 방법이 포장으로 바뀌고 픽업 장소가 새로 표시된다. 주소가 지워진 것만으로 전환이 확정됐다고 판단하지 않는다.
매장 시그니처 병음료 보관|병음료와 포장 음식을 함께 주문한 손님은 픽업 창구에서 병음료를 따로 포장해 달라고 요청할 수 있다. 주문표에 병 수량을 기록한다.|기울이면 새는 용기로 가져온 경우 직원이 봉투를 추가로 안내한다. 포장 용기의 반환 조건은 음료 용기 규정을 따른다.|전화 문의만으로는 병음료가 따로 포장됐는지 확인할 수 없다. 수령 전 주문대로 병음료가 준비됐는지는 픽업 담당자가 조회한다.
픽업 예정 시각 지나친 음식|포장 음식 예정 시각이 20분 지났을 때는 앱 주문 상세로 늦는 시각을 남긴다. 직원은 메뉴별 보관 가능 시간과 다시 조리가 필요한지 안내한다.|실온 상태를 오래 유지한 제품은 재포장해서 같은 주문으로 건네지 않는다. 재조리 비용은 주문 지연 원인과 관리를 확인한 다음 결정한다.|다시 조리한 음식은 새로운 준비 시각이 영수증에 기록된다. 예상 안내만 받은 주문의 재조리 여부는 매장 확인이 필요하다.
종이 영수증 없이 포장 찾기|종이 영수증이 없어도 앱의 현재 주문번호와 수령용 확인 숫자를 보여 주면 포장 출고를 요청할 수 있다. 주문자의 개인정보 전체를 제출할 필요는 없다.|앱 접속이 막힌 경우 결제 승인 시각과 주문 번호를 직원에게 제시한다. 카드 번호나 비밀번호를 공개 채널에 적지 않는다.|직원이 주문이 이미 나갔는지 조회한 뒤 수령 가능 여부를 안내한다. 주문 내역 화면을 열 수 있다는 사실은 상태 확인과 다르다.
문 앞 포장 수령 변경|접근이 어려운 손님은 앱의 수령 방식 메뉴에서 방문 15분 전까지 옆 출입문 인계를 신청할 수 있다. 지정 문은 픽업 시각에만 연다.|동시 방문이 많으면 직원이 기존 창구 또는 대기 공간으로 장소 변경을 안내한다. 짐 보관 서비스는 문 앞 인계에 포함되지 않는다.|직원이 문 위치와 수령 시각을 확인해 변경 표시를 남긴 뒤 안내한다. 메뉴 선택만 남아 있는 요청의 처리 상태는 조회한다.
포장 소스 동봉 제외|포장 소스를 제외하려면 결제 전에 해당 메뉴의 포장 옵션에서 제외를 선택한다. 결제 후에는 조리 시작 전에 앱 문의로 요청한다.|조리에 이미 섞인 소스는 별도로 뺄 수 없다. 성분 확인이 필요한 경우 알레르기 확인 절차를 안내한다.|주문표의 소스 항목 수정과 조리 담당자의 확인이 모두 기록된 경우 반영으로 본다. 앱 문의 접수와 조리 반영은 다른 기록이다.
여러 사람의 포장 주문 라벨|여러 사람의 메뉴를 구분하려면 결제 전에 봉투별 별칭을 주문 메모에 적는다. 별칭은 봉투당 열두 글자 이내의 숫자나 별칭으로 접수한다.|긴 실명·연락처·직장 정보는 포장 봉투에 인쇄하지 않는다. 용기가 비슷한 메뉴는 안전한 별칭 두 개로 구분한다.|라벨이 빠졌다는 제보는 주문 번호와 포장 담당자가 확인한 봉투를 대조한다. 어떤 메뉴가 어느 봉투에 배치됐는지 공개 답글에서 추정하지 않는다.
보건 확인용 포장 라벨 재발급|제품명·포장 시간이 적힌 용기 라벨을 잃은 경우 수령 당일 포장 창구에 구매 번호를 가져간다. 원래 발급된 정보를 근거로 한 번만 재출력한다.|먹다 남은 용기의 보관 시각이나 낱개를 나눈 시각은 매장에서 다시 인증하지 않는다. 포장 사실과 이후 사용 이력은 별도로 본다.|재발급한 라벨은 주문 기록에 사본으로 표시한다. 방문 예정 확인에는 새 라벨을 이미 받았다는 문구를 사용하지 않는다.
포장 진열대의 착오 신고|진열대에서 번호가 같은 다른 봉투를 가져온 것으로 의심되면 즉시 전화 또는 앱 문의로 수령 시각과 표시 번호를 전달한다. 다른 고객에게 직접 연락하지 않는다.|주문 목록을 열어 직원이 문제를 확인할 때까지 음식은 다른 사람에게 건네지 않는다. 교환 가능 여부는 개봉·보관 상태를 보고 안내한다.|실제 교환이나 재조리 완료는 음식 재인계 기록에서 확인한다. 신고를 받았다는 알림으로 환불이나 재포장을 약속하지 않는다.
용기 납작 포장 요청|납작한 상자가 필요한 메뉴는 주문 옵션에서 가방 수납형 포장을 선택한다. 메뉴별로 가능한 상자 높이를 결제 전에 표시한다.|소스가 흐르기 쉬운 메뉴는 높이 제한에 맞는 경우에만 납작 포장을 제공한다. 직원이 가능한 대체 용기를 안내할 수 있다.|변경된 포장 종류는 조리 전 주문 메모와 출고표에서 확인한다. 고객의 상자 교체 여부를 보관함 사진으로 추정하지 않는다.

## 제22장 배달과 공동 주문
공동 주문 마감 시각|오지 공동 주문의 참가자는 대표가 공유한 링크에서 마감 15분 전까지 메뉴와 옵션을 제출한다. 대표는 마감 때 현재 목록을 주문으로 확정한다.|대표가 마감 전에 공동 주문을 닫으면 늦게 선택한 참가자는 다시 열기 요청을 보낸다. 이미 결제된 주문은 개별 추가 주문을 이용한다.|참가 완료는 공동 주문 화면의 확정 목록에 자신의 별칭이 표시될 때 확인한다. 메뉴를 담은 장바구니만으로 결제 여부를 판단하지 않는다.
배달 출입증 발급 건물|출입증이 필요한 건물은 결제 전 요청란에 접수처 위치와 방문 가능 시간을 적는다. 기사에게 전달한 정보에는 출입 비밀번호 전체를 적지 않는다.|경비실이 인계를 받을 수 없는 경우 주문자가 허용한 대체 장소를 앱에서 확인한다. 출입증 통과 시각을 보장하지 않는다.|기사 통과와 실제 음식 인계는 배달 상세에서 따로 표시한다. 경비실 배달 완료 여부는 기사 기록을 직원이 확인한다.
사무실 층별 단체 배달|여러 층에서 받을 단체 주문은 주문 대표자가 층별 봉투 수와 한 곳의 대표 연락처를 제출한다. 기본 인계 위치는 건물 로비다.|기사의 여러 층 이동은 건물 허용과 예약된 인계 시간 안에서만 요청할 수 있다. 중간 층이 출입 불가이면 대표가 로비에서 받는다.|층별 수량 확인을 남겼는지는 주문표와 기사 인계 기록을 대조한다. 팀의 일부가 로비에 도착한 사실만으로 모두 인계됐다고 안내하지 않는다.
픽업 배달 혼용의 포인트|한 주문에서 배송이 두 단계로 나뉜 경우 포인트 반영 기준은 최종 결제 가격과 대표 주문 번호다. 배달과 포장 사이에서 포인트를 두 번 적립하지 않는다.|결제가 나뉜 경우 공동 주문 대표에게 전부 적립한다고 약속하지 않는다. 일반 포인트 예외는 제25조와 제110조를 함께 확인한다.|포인트 표시가 맞는지는 계정별 원장과 취소 내역을 직원이 비교한다. 보관·픽업 영수증만으로는 적립 완료를 확인할 수 없다.
우편함 옆 배달 인계|공동 현관 배달을 우편함 옆에 놓으려면 결제 전에 공용 구역에 음식 보관이 허용되는지 확인하고 메모를 남긴다. 기사에게 도착 연락을 요청할 수 있다.|보행로를 막거나 건물이 음식 보관을 금지하면 로비에 두지 않는다. 주문자와 연락이 안 될 때는 배달 안전 절차에 따라 이동한다.|우편함에 음식이 놓였는지는 기사 사진 기록과 인계 시각을 확인한다. 건물에 도착한 좌표만으로 실물 보관을 단정하지 않는다.
배달 위치 지도 수정|도로가 접한 다른 출입구로 배달받으려면 결제 후 5분 안에 앱 지도의 위치 핀과 메모를 업데이트한다. 주소의 건물명은 유지한다.|배달이 시작된 뒤에는 기사에게 앱 문의로 위치 변경을 제안할 수 있다. 다른 배송지일 경우 복수 주소 규정을 먼저 적용한다.|지도 위치가 바뀌면 앱에 수정 시각이 기록된다. 기사에게 새 정보를 전달했는지는 기사 확인 표시로 확인한다.
전달 사진 설명 추가|배달 완료 사진에 대한 설명이 필요하면 주문 후 24시간 이내에 동일 주문에서 문의한다. 직원은 사진과 배달 시각을 비교해 인계 위치를 확인한다.|사진에 제삼자가 보이면 공개 리뷰에 사진을 다시 첨부하지 않는다. 필요한 가림 처리는 문의 창에서 진행한다.|사진이 교체됐는지 또는 설명이 전달됐는지는 담당자의 답변이 등록된 뒤 확인한다. 기사와 고객이 각각 주장한 위치는 기록 대조 후 판단한다.
엘리베이터 비운행 배달|엘리베이터가 운행하지 않는 건물은 앱 배달 메모에 운행 중지 시간과 인계 가능한 층을 적는다. 배달이 시작되기 전에 정보를 공유한다.|계단 이용이 제한된 건물은 기사에게 짐을 들어 이동하도록 요구하지 않는다. 로비나 경비실의 대안을 주문자와 합의한다.|층별 인계 위치가 바뀌었으면 기사와 주문자의 확인 시간을 기록한다. 건물 출입이 접수됐다는 메시지로 실제 배달 완료를 판단하지 않는다.
연구실 출입 제한 배달|연구실 출입이 제한된 주소에서는 건물 외부 안내 데스크를 대표 수령지로 등록한다. 출입 승인 신청은 주문 측에서 미리 진행한다.|연구실 내부에 보관할 음식은 허용된 냉장 보관 장소가 있는 때에만 직원이 안내한다. 배달 기사가 출입 절차를 대신 신청하지 않는다.|안내 데스크 인계는 직원이 주문번호와 수령 위치를 확인한다. 출입증이 발급돼도 연구실 안으로 음식이 전달됐는지는 따로 본다.
아파트 동 번호 오기 신고|아파트의 호수와 동 번호를 잘못 적은 경우 주문 상세에서 확인한 뒤 기사 인계 전에 즉시 수정한다. 같은 단지 내 변경만 해당한다.|다른 건물로 옮기는 경우 비용과 거리 확인이 필요하다. 이미 배달된 음식은 담당자가 배달 기록부터 확인한다.|주소가 수정되면 주문 상세에 수정 시각이 표시된다. 어떤 동에 건넸는지 확인하려면 기사 인계 기록을 대조한다.
공동 주문 일부 품절 대체|공동 주문의 일부 메뉴가 품절되면 대표에게 현재 가격과 대체 옵션을 안내한다. 대표는 한 명씩 선택을 받거나 해당 메뉴 분리 취소를 요청한다.|원래 메뉴와 알레르기 정보가 다른 대체 메뉴는 자동 교체하지 않는다. 회신 기한이 지나면 해당 주문 준비를 보류하고 대표에게 연락한다.|대체 완료 목록에는 원래 메뉴와 새 메뉴가 모두 기록된다. 대표가 링크를 열어 본 사실은 대체 동의가 완료됐다는 의미와 별도다.
차량 배달과 보행자 수령|차량 탑승이 어려운 건물 이용자는 배달 약속 시각 전에 차량 접근 금지 구간을 연락란에 적는다. 사람이 만날 수 있는 로비나 안내소를 지정한다.|공용 차량 통행로에 음식을 내려놓는 방식으로 바꾸지 않는다. 도착한 기사가 하차 가능한 위치를 앱으로 먼저 알린다.|보행자 인계 완료는 앱에서 수령 확인 번호가 등록된 뒤 확인한다. 차량 도착 알림만으로 손님 인계를 확정하지 않는다.
배달 예약의 당일 앞당김|배달 예약을 앞당기려면 원래 시각 2시간 전까지 주문 상세에서 시간 변경을 신청한다. 준비 가능한 가까운 회차를 화면에서 제시한다.|주방 회차가 가득 차면 원래 예약을 유지하거나 주문 취소 기준을 안내한다. 주문 변경은 예상 배달 목표와 기사 배차를 따로 확인한다.|조정 완료 시 같은 주문 번호에 새 예약 회차가 표시된다. 앱 문의를 보낸 것만으로 배송 시각을 약속하지 않는다.
복층 행사장 보온 기록|두 층을 쓰는 행사 배달에는 대표 인계 위치와 보온 용기를 받을 담당자를 지정한다. 기사가 인계 시각을 주문 메모에 적는다.|개봉 후 층별 배분은 현장 대표가 담당한다. 층별 인계를 따로 요청하면 일반 배달 인계 범위와 가능 시간부터 확인한다.|보온 용기 인계 완료는 수량과 대표 서명이 함께 기록될 때 확인한다. 음식의 이후 온도나 층별 수령 상황을 대신 확정할 수 없다.
배달 수령인 연락 두절|수령인 연락이 닿지 않으면 기사는 앱에서 전화와 도착 알림으로 각각 한 번 연락한다. 허용된 사진 인계 장소가 등록돼 있으면 그 지시를 따른다.|공동 현관 밖에 둘 수 없고 허용 장소도 없으면 매장에 상황을 전달한 뒤 담당자 안내를 기다린다. 현장 추측으로 다른 주소에 맡기지 않는다.|실제 반송 상태는 기사와 매장이 기록한 시간과 음식 수량을 대조해 확인한다. 전화 실패 기록만으로 환불을 확정하지 않는다.

## 제23장 결제와 증빙
승인 기록 문자 재전송|결제 확인 문자를 다시 받으려면 주문 당일 앱 주문 상세에 등록된 기기로 재전송을 누른다. 발송 기록은 주문번호별로 남긴다.|다른 사람의 번호로는 주문자가 앱 알림 수신처를 먼저 변경한 뒤 재전송할 수 있다. 카드 번호를 문자로 보내지 않는다.|재전송 완료 기록은 발송 시각과 처리 상태를 표시한다. 통신사에서 실제로 수신됐는지는 기기와 발송 이력을 대조한다.
사업자 지출 증빙 정정|사업자 지출 증빙의 번호를 잘못 넣었으면 발행 당일 앱 문의에 원래 발행 번호와 수정할 사업자등록번호를 등록한다. 담당자는 발행 상태를 먼저 확인한다.|이미 정산이 마감된 증빙은 먼저 이전 건의 취소 가능 여부를 확인한다. 결제 수단이 개인용 상품권이면 사업자 증빙 발행 조건이 다를 수 있다.|정정 완료는 새 증빙 번호와 이전 증빙의 취소 기록이 모두 있는지 확인한다. 현금 결제 내역만으로 수정 여부를 확정하지 않는다.
공동 카드에 선결제 영수증|단체가 한 장으로 선결제했다면 결제한 사람에게 원본 영수증을 발급하고 각 참가자에게는 메뉴 정산 표시를 보여 준다. 영수증은 대표 주문 번호로 관리한다.|각 참가자에게 같은 승인 건의 별도 카드 영수증을 중복 발행하지 않는다. 비용 정리용 사본은 정산 문서에 표시한다.|사본이 발행됐는지는 대표 주문의 발행 로그에서 시각과 종류를 확인한다. 개인별 카드 청구 완료를 대신 판단하지 않는다.
정기 식사권의 미사용 표시|정기 식사권에서 남은 사용 횟수는 앱 식사권 메뉴에 표시된다. 주문 결제가 끝난 경우에만 그날 사용분이 한 번 차감된다.|당일 주문 취소가 접수되면 차감 유지 또는 복구를 원장 확인 후 안내한다. 실수로 결제한 식사권은 먼저 사용 기록을 확인한다.|실제로 횟수가 복구됐는지는 원장과 취소 완료 상태를 함께 조회한다. 예상 잔여 횟수는 화면 반영 전의 사용 가능 보장으로 취급하지 않는다.
거래명세서의 메뉴 수량|거래명세서에는 결제 당시 주문에 포함된 메뉴와 수량을 기재한다. 고객이 원하면 알레르기 표기 변경 이력도 주문 메모에서 안내한다.|영수증 발행 후 주문자가 따로 구입한 품목을 같은 거래명세서에 추가하지 않는다. 영수증과 결제 내역이 다르면 각각의 주문 번호를 확인한다.|명세서가 발급됐는지는 발행 대장의 문서 번호와 발송 시각을 확인한다. 거래명세서만으로 금융기관의 최종 승인 상태를 확정하지 않는다.
카드 승인과 계좌 이체 이중 수납|카드 승인과 별도 이체를 모두 했다고 신고하면 앱 문의에 주문 번호와 두 결제의 시각을 남긴다. 담당자가 같은 주문의 결제인지 구분한다.|다른 예약금 또는 상품권 충전 거래가 포함됐다면 중복 수납으로 자동 처리하지 않는다. 서로 다른 용도의 영수증을 먼저 확인한다.|중복 확인과 반환 처리는 각각의 기록이 남은 뒤 완료로 안내한다. 화면에 승인 내역 두 줄이 보여도 이미 반환됐다고 답하지 않는다.
갱신된 예약금 증빙|예약일이 변경된 단체의 예약금 증빙은 기존 거래 번호와 변경된 날짜를 함께 표시한다. 날짜가 달라져도 같은 수납 건임을 알 수 있게 한다.|예약금이 일부 반환됐으면 반환액을 별도 줄로 기재한다. 새 예약금을 낸 경우에는 새로운 거래 번호를 발급한다.|변경 증빙 발급 여부는 예약금 수납 대장과 문서 대장으로 확인한다. 예약일 달력만으로 증빙 발행을 확정하지 않는다.
매장 키오스크 지출 내역|키오스크 영수증 출력이 끊긴 경우 결제 완료 화면의 주문 번호를 카운터에 보여 준다. 해당 주문 번호로 종이 사본을 받을 수 있다.|화면이 초기화되고 주문 번호를 모르면 대략적인 승인 분과 결제 금액으로 직원이 거래를 찾는다. 이어서 같은 주문의 재결제를 요구하지 않는다.|키오스크 주문과 카드 승인 기록을 대조해 발행 여부를 확인한다. 사본을 요청한 기록은 승인이나 결제 취소를 증명하지 않는다.
월말 단체 청구서 수신인|월말 단체 청구서 수신인은 대표 계약자의 등록 메일로 지정한다. 변경 요청은 다음 청구일 전 영업일 16시까지 담당자에게 전달한다.|제삼자의 요청만으로 수신인을 바꾸지 않는다. 이미 발송한 청구서는 담당자의 변경 확인 뒤 새 메일로 추가 발송한다.|수신인 변경은 승인한 담당자와 갱신 시각이 청구 기록에 남아야 확인한다. 메일 조회 상태와 수신 주소 변경 상태는 구분한다.
분할 결제의 최소 수납액|매장 분할 결제는 계산을 시작하기 전에 인원과 각 수납 금액을 직원에게 알린다. 한 사람이 맡은 금액은 3천 원 이상으로 등록한다.|현금 포함 결제가 맞지 않으면 남은 잔액을 대표로 합쳐 다시 확인한다. 일부 카드 승인 이후에는 승인된 금액을 먼저 지우지 않는다.|최종 영수증은 여러 승인 건과 남은 잔액 0원을 함께 확인한 뒤 발행한다. 앱 메모만으로 개인의 결제 성공을 확정하지 않는다.
청구 통화 확인|외국 카드 결제 전 키오스크가 표시한 청구 통화를 확인하고 선택한다. 매장은 영수증에 선택 통화와 매장 금액을 각각 표시한다.|카드사의 환전 수수료나 실제 청구 환율은 매장 영수증의 금액만으로 단정할 수 없다. 카드사 조건을 함께 확인한다.|선택 통화가 맞는지는 원본 영수증과 단말기 승인 정보를 대조한다. 최종 환전은 발급 카드사의 내역으로 확인한다.
선불 예치금 잔액 확인|선불 예치금은 계정 메뉴에 충전·차감·환불 내역을 따로 표시한다. 날짜별 거래 상세에서 매장 주문 번호를 확인할 수 있다.|공동 주문 대표 계정의 잔액을 참가자에게 공개하지 않는다. 등록 명의자가 필요한 주문 내역만 조회한다.|실제 잔액 누락 문의는 충전·차감·반환 원장을 확인해야 한다. 매장에서 사용 가능하다고 공개 답글로 먼저 약속하지 않는다.
임시 승인 보류의 문의|임시 승인이 오래 보이는 경우 앱 문의에 승인 금액과 주문이 완료됐는지를 같이 적는다. 매장 담당자는 결제 요청 계층을 확인한다.|새 결제 시도를 하기 전에 기존 주문이 정상 발행됐는지 직원에게 확인한다. 카드사 사고 접수가 있는 경우 발급 기관 안내를 따른다.|임시 승인 해제 여부는 매장 취소 기록과 카드사 반영 상태를 각각 확인한다. 매장 처리 시각을 카드사 반영 시점으로 바꾸어 안내하지 않는다.
기간 지정 합산 영수증|동일 계약 계정은 주문 목록에서 원하는 기간을 지정하고 합산 명세서 발급을 신청할 수 있다. 월을 넘겨 최대 60일 범위까지 조회한다.|서로 다른 계약 계정이나 개인 결제를 합산하려면 접근 권한과 의뢰 근거를 먼저 확인한다. 일반 손님은 본인 거래만 조회한다.|발급 완료는 선택 기간과 문서 번호를 받았을 때 확인한다. 월별 주문 수를 문의하면 문서가 실제로 발급된 상태도 별도로 확인한다.
세금 증빙 중복 제출 취소|같은 거래의 세금 증빙을 두 번 제출했다고 느끼면 담당자에게 두 문서 번호를 전달한다. 접수 기록에서 제출 경로를 확인한다.|거래가 다른 경우 금액이 같아도 중복 접수를 바로 취소하지 않는다. 담당자가 원거래와 문서 번호를 연결해 판단한다.|중복 제출 취소는 남은 유효 문서와 철회 기록을 대조한다. 기존 영수증이 여전히 보인다는 이유로 취소 실패를 확정하지 않는다.

## 제24장 취소와 환불 예외
픽업 전 일부 메뉴 조리 취소|픽업 전 일부 메뉴를 취소하려면 해당 메뉴가 조리를 시작하기 전에 앱 주문 상세에서 메뉴를 선택한다. 남은 메뉴의 원래 픽업 시간은 주문표에 표시한다.|묶음 할인으로 주문한 메뉴 일부를 빼는 경우 남은 결제 금액을 다시 안내한 뒤 승인한다. 다른 메뉴의 취소까지 자동 적용하지 않는다.|메뉴별 취소 완료는 해당 메뉴 가격과 원결제 조정 기록을 대조한다. 주문 전체가 취소됐는지 확인할 때는 상태를 따로 조회한다.
품절 대체 동의 뒤 차액 반환|품절 후 더 저렴한 메뉴로 바꾸기로 동의한 경우 원래 항목과 대체 항목의 금액 차액을 계산한다. 결제 수단에 맞는 반환 절차를 안내한다.|알레르기 자료를 요청한 메뉴는 성분 확인이 끝날 때까지 자동 교체하지 않는다. 할인 적용을 다르게 계산해야 하면 먼저 이유를 안내한다.|차액 반환 완료는 대체 주문 확정과 결제 조정 기록을 모두 확인한다. 대체 메뉴 제공 사실만으로 카드 반영 완료를 단정하지 않는다.
기상 취소의 예약금 이월|매장이 기상 사유로 야외 행사를 취소하면 대표는 같은 종류의 다음 예약에 예약금을 한 번 이월하거나 반환을 신청할 수 있다. 이월 가능한 날짜를 안내한다.|기상 사유 취소 이전에 손님이 자진 취소한 경우 원래 예약 조건을 적용한다. 이월 가능한 회차가 없으면 반환 선택을 제공한다.|이월이 완료되면 새 예약 번호에 기존 예약금 금액이 표시된다. 새로운 회차가 공개됐다는 사실만으로 개인 이월을 확정하지 않는다.
단체 메뉴 일괄 취소 확인|단체 메뉴의 전체 취소는 대표자가 주문 번호와 포기하는 메뉴 목록을 확인해 접수한다. 조리 착수 내역을 담당자가 나눠 확인한다.|아직 조리를 시작하지 않은 메뉴가 있으면 일부 취소안도 함께 제시할 수 있다. 방문 예약 철회와 메뉴 취소는 각각 기록한다.|완료 확인 때는 취소된 메뉴 목록, 예약 상태, 반환 완료 내역을 각각 본다. 대표가 연락했다는 기록은 처리 완료의 근거로 쓰지 않는다.
취소 승인 전 재주문|취소 승인 전에 같은 메뉴를 다시 주문하려는 경우 기존 주문이 실제 중단됐는지 앱 상세에서 확인한다. 중단 확인 전에는 두 주문이 준비될 수 있다.|원래 주문에 준비 완료가 표시됐으면 새 주문과 별도로 보관 절차를 안내한다. 같은 결제 금액만 보고 두 주문을 자동 병합하지 않는다.|기존 주문 취소 여부는 원래 번호의 종료 기록으로 확인한다. 새 주문 수령이 완료됐어도 기존 결제 반환 상태는 따로 본다.
냉장 메뉴 인계 뒤 교환 접수|냉장 메뉴의 포장 이상을 발견하면 수령 2시간 이내에 주문 번호와 포장 상태를 앱 문의로 전달한다. 담당자가 사진과 출고 이력을 확인한다.|수령 이후 개봉되거나 다른 용기로 옮겼다면 판단에 필요한 보관 상황을 먼저 묻는다. 공개 답글에서 먹어도 된다고 보장하지 않는다.|교환 완료는 새 메뉴 수령과 기존 품목 회수 또는 폐기 확인이 기록된 경우에 안내한다. 접수 사진만으로 환불·교환 완료를 확정하지 않는다.
시간 지정 쿠폰의 금액 반환|특정 회차에만 쓸 수 있는 쿠폰이 들어간 주문을 취소하면 반환 금액은 쿠폰을 제외한 실제 결제액을 기준으로 계산한다. 쿠폰 복구 조건은 발급 채널의 정책을 따른다.|유효 회차를 이미 지나면 복구 가능 기간을 발급처와 확인한다. 다음 회차에서도 쓸 수 있다고 자동 안내하지 않는다.|실제 쿠폰이 돌아왔는지는 발급처 내역과 주문 반환 상태를 각각 확인한다. 카드 조정이 끝나도 쿠폰 상태는 별도로 본다.
배달 예약금과 식사 대금 분리 반환|예약금과 식사 대금을 따로 낸 단체는 반환 요청 때 영수증 두 건을 같이 제시한다. 항목마다 실제 결제 수단과 취소 조건을 적용한다.|예약금에 취소 제한일이 지났어도 아직 조리하지 않은 식사 대금은 별도로 확인한다. 총액에 같은 비율을 일괄 적용하지 않는다.|한 항목만 반환됐는지 확인하려면 두 거래 번호의 최신 상태를 각각 조회한다. 결제 하나의 취소 문자로 둘 다 처리됐다고 답하지 않는다.
패키지 예약의 방문 날짜 변경|날짜 지정 패키지의 변경은 방문 이틀 전 오후 3시까지 앱의 변경 요청으로 접수한다. 기존 패키지 구성과 방문 지점은 유지된다.|새 날짜에 같은 재료를 받을 수 없으면 직원이 대체 구성과 기존 예약 유지 중 선택을 안내한다. 품목을 임의로 바꾸지 않는다.|날짜 변경이 승인됐으면 새 회차와 적용 메뉴가 예약 상세에 함께 표시된다. 변경 신청 메시지로 패키지 재고를 보장하지 않는다.
환불 입금 계정 변경|계좌 반환이 필요한 경우 결제 수단의 등록 명의자가 앱 문의로 변경을 신청한다. 담당자는 원래 반환 대상과 승인 이유를 기록한다.|이미 이체가 시작된 계좌는 새 번호로 곧바로 변경할 수 없다. 금융기관의 거래 상태를 확인하고 다음 요청을 안내한다.|새 계좌로 반환했는지는 은행 이체 증빙과 처리 대장을 확인한다. 공개 답글에 계좌 전체 번호를 노출하지 않는다.
동일 메뉴 재배송 비용|누락이나 오배송으로 같은 메뉴를 다시 보내는 경우 직원이 원피해 사유를 확인한 뒤 재배송 비용을 안내한다. 최초 오류 확인 전 자동 차감은 하지 않는다.|요청한 대체 메뉴의 가격과 배달 거리가 달라지는 경우 추가 금액을 먼저 확인한다. 기본 재배송을 선택할 수 있는지 안내한다.|재배송 완료는 기사 인계 기록과 새 주문 번호의 수령 시각을 확인해야 한다. 새 배송을 요청했다는 사실만으로 완료를 확정하지 않는다.
상품권 주문의 중복 승인 방지|상품권과 카드 차액을 함께 낸 주문이 중복됐다고 보이면 원래 주문 번호와 두 영수증을 앱에 등록한다. 사용한 상품권 종류와 상태를 확인한다.|상품권 잔액을 공개 채널에서 문의하도록 유도하지 않는다. 대행 판매 상품권은 발급처의 원장 확인이 필요할 수 있다.|상품권 차감 복구와 카드 승인 취소는 각각 반영 시점이 다르다. 두 수단이 모두 반영됐는지 직원이 기록을 대조한다.
선결제 좌석 추가비 확인|선결제 좌석의 인원이 바뀌면 추가비 적용 인원과 원래 인원을 앱 예약 상세에서 확인한다. 변경 시점에 표시된 인원 기준을 적용한다.|좌석만 바꾸고 실제 인원이 같다면 자동으로 추가비를 청구하지 않는다. 좌석 등급 차액이 있으면 직원이 먼저 내용을 안내한다.|실제 추가비 승인 여부는 좌석 정보와 결제 내역을 함께 확인한다. 예약 목록의 인원 숫자만으로 청구됐다고 판단하지 않는다.
분실한 이벤트 티켓의 반환|실물 이벤트 티켓을 잃은 경우 입장 시작 전 주문 번호와 본인 확인으로 티켓 기록을 찾을 수 있다. 동일 주문의 취소 조건을 먼저 확인한다.|이미 입장 처리된 티켓은 직원이 입장 기록을 검토하기 전 반환을 확정하지 않는다. 티켓 번호만 제삼자에게 보내지 않는다.|반환 완료는 주문 처리 내역과 입장 재사용 제한 상태를 대조한다. 현장 입장을 철회했다는 말만으로 금융 반영을 확인하지 않는다.
포장 봉투 변형 신고와 부분 환불|포장 봉투 파손으로 일부 메뉴를 받지 못한 경우 수령 시각과 피해 메뉴를 주문 번호와 함께 앱 문의에 남긴다. 직원은 해당 항목의 출고 기록을 확인한다.|겉봉투가 구겨졌지만 내용물이 정상이라면 교환 요청과 부분 환불 요청을 구별해 접수한다. 안전이 의심되면 음식 상태부터 확인한다.|부분 반환 완료는 대상 메뉴와 확정 금액이 주문 취소 내역에 표시된 뒤 안내한다. 전체 주문은 입금 여부를 각각 확인한다.

## 제25장 앱과 적립 및 쿠폰
적립 누락 신고 기한의 연장|제110조의 일반 구매 적립 신고 기한은 14일이다. 앱 오류가 공개 공지된 날의 주문은 오류 종료일부터 7일 이내에 접수할 수 있다.|리뷰 포인트는 제118조의 주문 일치 확인을 적용한다. 일반 구매 포인트 오류 공지를 리뷰 적립까지 자동 적용하지 않는다.|연장 접수를 한 건의 실제 적립 여부는 직원이 오류 공지 기간과 포인트 원장 반영을 대조한다. 접수 번호를 받았다는 사실로 적립을 확정하지 않는다.
장기 미접속 쿠폰 표시|장기 미접속 계정은 앱의 보안 확인을 마치면 보유 쿠폰 목록을 열 수 있다. 쿠폰별 발급처와 만료일을 함께 표시한다.|제휴사가 발급한 쿠폰의 전체 내역은 발급처에서 먼저 확인한다. 앱에서 보이지 않는다는 이유로 일반 재발급을 약속하지 않는다.|오지 발급 쿠폰의 실제 복구 여부는 발행 번호와 복구 처리일을 비교해 안내한다. 로그인 성공 시각만으로 판단하지 않는다.
주문 메모 복사 기능|최근 주문 메모를 다음 주문에 복사하려면 결제 전 메모 편집에서 문구를 검토한다. 연락처와 출입 비밀번호는 복사 대상에서 뺀다.|받는 지점이나 배송지가 달라지면 접근 가능 여부를 새로 확인한다. 이전 매장의 예외 처리 결과는 주문 메모를 복사해도 적용되지 않는다.|어떤 문구가 실제로 주문에 전달됐는지는 결제 완료 주문 메모를 확인한다. 편집 화면의 임시 글로 반영 여부를 단정하지 않는다.
가족 계정의 쿠폰 이전|가족 계정으로 양도할 수 있다고 표시된 쿠폰은 앱 쿠폰함에서 받는 계정과 사용 기한을 확인한 뒤 이전한다. 한 쿠폰은 한 번만 옮긴다.|양도 제한 표시가 있는 쿠폰은 계정 간 이동할 수 없다. 포인트와 결제 잔액의 이동은 따로 정한 규정을 적용한다.|쿠폰 이전은 원래 계정에서 사용 종료되고 새 계정에 동일 번호가 나타날 때 완료한다. 상호 계정의 상태는 직원이 확인한다.
로그인 기기 변경과 주문 보기|기기를 바꾼 손님은 주문 계정으로 로그인한 뒤 주문내역을 열 수 있다. 처리 중 주문은 수령 방식과 예약 시각을 다시 확인할 수 있다.|비회원 주문은 계정 주문 목록에 자동 합쳐지지 않는다. 비회원 주문 번호로 앱 문의에 연결을 요청할 수 있다.|비회원 주문 연결 여부는 새 계정 주문 상세와 원래 주문 번호를 대조한다. 로그인한 사람의 실제 주문도 직원 확인 없이 추정하지 않는다.
리뷰 포인트의 사진 삭제|리뷰 사진을 지우려는 손님은 현재 지급 내역과 제33조 리뷰 적립 기준을 먼저 확인한다. 사진 삭제는 리뷰 편집에서 처리한다.|사진 삭제 뒤 받을 기준이 달라질 수 있다. 지급 전에 이미지가 없으면 글 리뷰 기준을 적용한다.|리뷰 포인트 재산정이 완료됐는지는 지급 원장과 최종 리뷰 버전을 대조한다. 사진을 지웠다는 말만으로 차감 여부를 확정하지 않는다.
한정 앱쿠폰의 매장 변경|특정 지점 전용 앱 쿠폰은 쿠폰 상세에 표시된 매장에서만 쓸 수 있다. 방문할 곳을 고른 뒤 그 지점에 해당 쿠폰이 적용되는지 확인한다.|지점 운영이 일시 중지된 경우에는 발급처가 같은 행사의 대체 지점을 지정할 수 있다. 일반 쿠폰으로 자동 전환된다는 안내는 하지 않는다.|쿠폰 변경이 완료됐으면 새 지점과 기존 만료일이 쿠폰 상세에 표시된다. 매장 운영 공지만으로 개별 쿠폰 수정이 완료됐다고 답하지 않는다.
QR 적립 시각 표시|현장 QR로 포인트를 적립하려면 결제 뒤 30분 이내에 영수증 QR을 앱에서 인식한다. 승인된 주문 번호를 확인 화면에 표시한다.|QR 영수증을 다시 인식하면 동일 주문을 중복 적립하지 않는다. 만료된 QR의 일반 누락 적립에는 제110조를 적용한다.|QR 인식이 완료돼도 원장 반영 상태를 확인해야 포인트를 쓸 수 있다. 화면에는 접수와 반영 상태를 따로 표시한다.
오프라인 사용권의 온라인 전환|종이 사용권을 앱에 등록할 수 있다고 표시돼 있으면 앱 쿠폰 메뉴에 사용권 번호를 입력한다. 등록 시 원래 만료일을 유지한다.|절취선이 제거되거나 등록 번호가 훼손된 사용권은 직원의 실물 검토를 거친다. 타 발급처가 만든 교환권은 자체 정책을 따른다.|등록 완료 여부는 앱 번호와 실물 사용권 회수 기록으로 확인한다. 이후 실제 사용 내역은 주문 반환과 구분해 조회한다.
혜택 알림 중단|앱 혜택 알림을 중단하려면 설정의 마케팅 알림에서 항목을 해제한다. 기존 주문의 픽업 및 결제 안내는 계속 표시한다.|단말기의 전체 알림을 껐다면 주문 안내도 휴대전화 화면에 표시되지 않을 수 있다. 앱 주문 상세를 확인한다.|설정 반영 여부는 앱의 업데이트 시각과 기본 설정값을 확인한다. 이전 광고 메시지가 남아 있다는 사실만으로 오류를 확정하지 않는다.
정기 포인트 만료 안내|포인트 만료 월에는 앱 혜택함의 사용 가능 포인트와 만료 대상 적립분을 따로 표시한다. 만료 전 주문은 기존 사용 규칙을 적용한다.|취소된 주문에 사용한 포인트는 반환 당시 만료 상태를 추가로 확인한다. 모든 적립분 유효기간을 새로 설정하지 않는다.|현재 포인트의 사용 가능 여부는 적립분별 날짜와 취소 복구 상태를 원장에서 확인한다. 과거 잔액 화면만으로 사용을 약속하지 않는다.
비회원 혜택 내역 찾기|비회원 주문의 할인 내역은 알림을 받은 주문 링크에서 확인한다. 매장 방문 시에는 해당 주문의 할인 적용 목록을 제시할 수 있다.|계정 혜택은 비회원 결제에 자동으로 나중 적립되지 않는다. 재발행이 가능한지 주문 문의로 확인한다.|개인 혜택이 새 계정에 연결됐는지는 주문 번호와 할인 적용 기록을 대조한 뒤 안내한다. 주문을 조회했다고 할인까지 옮겼다고 답하지 않는다.
단체 담당자의 식사권 분배|단체 대표는 식사권 분배 화면에서 참가자별 수량과 만료일을 지정한다. 배포 전에 수량 합계를 한 번 확인한다.|이미 사용한 식사권은 단체 대표가 다른 참가자에게 재할당할 수 없다. 미사용 건은 계약 담당자가 수량 변경을 검토할 수 있다.|실제 분배 완료는 각 참가자의 초대 수락과 할당 번호를 함께 확인한다. 대표의 발송 내역만으로 개인 수령을 확정하지 않는다.
임시 쿠폰 코드 접근 장애|이벤트 쿠폰 코드 화면이 열리지 않으면 주문 결제 전에 앱 버전과 행사 이름을 기록한 뒤 문의한다. 행사 유효 시간은 공지로 확인한다.|장애 시간이 확정되면 발급처가 행사 연장 여부를 별도 공지한다. 문의 접수만으로 할인 기한이 연장되지는 않는다.|코드 복구 여부는 같은 계정에서 코드가 표시되고 발급 시간이 기록된 경우에 확인한다. 다른 손님의 스크린샷은 확인 근거가 아니다.
주문번호 마스킹 표시|앱 공유용 화면에서는 주문 번호 앞부분을 가려서 표시할 수 있다. 공개 후기에서 전체 번호를 그대로 첨부하지 않는다.|지급 확인처럼 원장과 연결해야 하는 요청은 앱 문의에서 전체 번호를 확인한다. 공유 화면의 식별 정보는 공개 안내에만 사용한다.|오래된 마스킹 화면의 주문을 직원이 확인하려면 확정 주문 번호나 거래 시간이 필요하다. 유사한 구매 내용만으로 실제 기록을 단정하지 않는다.

## 제26장 알레르기와 메뉴 표시
시즌 베이커리 성분표 조회|시즌 베이커리의 성분표는 메뉴 상세에서 제조일을 선택해 본다. 같은 이름이어도 제조일이 다르면 성분표 버전을 확인한다.|포장지 표기와 앱 내용이 다르면 구매 전 직원에게 제조일과 제품명을 알려 확인한다. 공개 답글에서 안전 여부를 보장하지 않는다.|특정 배치의 교차 접촉 여부는 담당자가 해당 제조 기록을 대조한다. 일반 성분표만 보고 이미 주문한 제품의 안전을 확정할 수 없다.
주방 도구 분리 요청|공용 조리대를 쓰는 메뉴는 주문 전 직원에게 조리 도구를 분리할 수 있는지 문의한다. 주문표에 필요 조건을 글로 남긴다.|조리 방식이나 작업 공간 때문에 도구 분리가 불가능하면 매장에서 가능한 대체 옵션을 안내한다. 알레르기 위험이 없다고 약속하지 않는다.|실제 도구 분리 여부는 담당자가 해당 주문의 조리 이력을 확인해야 한다. 주문 메모에 분리 요청이 있다는 사실과 완료를 구별한다.
앱 식단 선호와 알레르기, 직원 확인|식단 선호는 앱 메뉴 추천의 필터로 쓰인다. 알레르기 조건은 주문을 제출하기 전에 직원에게 확인해 주문 메모에 따로 적는다.|같은 채식 표시라도 제조 도구와 소스의 원재료가 다를 수 있다. 앱의 선호 필터만으로 교차 접촉이 없는 메뉴를 보장하지 않는다.|특정 주문의 조건 반영을 알려면 담당자가 제품과 조리 기록을 대조한다. 계정 선호 설정이 저장됐다는 표시는 조리 확인이 아니다.
한정 소스 대체 안내|한정 소스가 빠져 대체할 때는 메뉴 상세의 현재 소스와 성분표를 안내한다. 주문을 받기 전에 손님에게 선택을 요청한다.|제품 변경으로 알레르기 관련 조건이 달라지면 자동으로 대체하지 않는다. 원래 메뉴를 원하면 준비 가능 시간을 따로 확인한다.|대체 소스가 들어갔는지는 조리 담당자의 주문 확인 기록으로 조회한다. 재고 공지가 올라왔다고 개별 주문도 바뀌었다고 안내하지 않는다.
음료 얼음량 표시|주문 전 음료 얼음량을 기본·적게·없음 중 제공되는 범위에서 선택한다. 실제 음료 용량과 얼음량을 앱 상세에서 각각 설명한다.|재료에 얼음이 갈려 들어가는 음료는 얼음 없음 선택을 제공하지 않는다. 다른 차가운 메뉴를 고를 수 있다.|변경 접수는 주문표 옵션으로 확인한다. 이미 제조된 음료에 어떤 양이 들어갔는지는 담당자가 제조 상태를 확인해야 한다.
유제품 분리 포장|가능한 메뉴의 유제품 토핑은 결제 전에 분리 포장을 선택할 수 있다. 분리 포장 표시가 있는 메뉴만 접수한다.|반죽에 유제품을 넣은 품목은 토핑을 따로 포장해도 유제품이 남는다. 직원이 제품 성분을 따로 확인한다.|실제 분리 포장 여부와 반죽 성분은 각각 포장 확인표와 성분표를 본다. 두 항목이 모두 확인되기 전에는 안전을 보장하지 않는다.
조리 버전별 맵기 차이|계절별 새 버전의 맵기 표는 메뉴 상세에서 선택한다. 포장 주문과 매장 식사에 제공하는 맵기의 기준은 메뉴별로 표시한다.|재료 품절로 조리법을 바꾸는 경우 새 맵기와 원재료를 안내한 뒤 선택을 받는다. 변경을 원하지 않으면 기존 가능한 메뉴를 보여 준다.|실제 적용 맵기는 출력된 주문 옵션과 조리 기록을 비교한다. 앱 기본값을 보고 해당 주문의 맵기를 확인할 수 없다.
공유 용기의 집게 교체|행사 중 공유 식품을 제공할 때 집게는 용기별로 지정한다. 집게가 다른 용기에 닿으면 직원이 사용을 멈추고 교체한다.|교체 이전에 닿은 음식은 새 집게를 놓았다고 안전 상태가 결정되지 않는다. 행사 담당자가 제품과 접촉 상황을 확인한다.|개별 용기의 접촉 여부는 교체 시간과 담당자 보고를 확인해야 한다. 다른 용기를 봤다는 이유로 같은 결과를 안내하지 않는다.
글루텐 관련 표시 확인|제품 상세에는 표시 대상 원재료와 확인한 성분표 버전을 게시한다. 특정 알레르기가 있으면 주문 직전에 직원에게 문의한다.|성분표에 없는 항목이라도 조리 도구 공유 여부는 별도로 확인한다. 광고 문구가 사용 적합성이나 안전을 보장하지 않는다.|특정 주문에서 확인한 조리 조건은 직원 답변의 기록으로 대조한다. 고정 문구를 읽는 것만으로 주문 결과를 답하지 않는다.
레시피 교체일의 포장 제품|원재료가 바뀌는 날에는 조리 시각과 용기 라벨에 적용한 버전을 표시한다. 메뉴명은 그대로 유지될 수 있다.|기준 시각 전후의 재고를 섞어 써야 하면 포장 라벨에 실제 적용 버전을 기록한다. 정확하지 않으면 직원 확인을 요청한다.|구매한 제품이 전후 어느 버전인지는 생산 기록과 판매 라벨을 대조한다. 결제 시각 하나만으로 성분을 단정하지 않는다.
테이블 시식 샘플 거절|공용 테이블 시식 샘플이 필요 없으면 주문 전에 직원에게 알려 별도 제공을 요청하지 않을 수 있다. 메인 메뉴 가격은 그대로 표시한다.|허락 없이 다른 테이블의 샘플을 가져오지 않는다. 성분이나 재료 문의가 있으면 제출된 시식표를 확인한다.|해당 테이블에 샘플이 실제 제공됐는지는 직원 확인이 필요하다. 테이블 주문서에 샘플 목록이 있다는 사실과 제공을 구분한다.
메뉴 설명 이미지의 예시 표시|메뉴 이미지의 제공량은 이미지의 예시 문구와 주문 상세 설명을 함께 참조한다. 추가 토핑은 주문 화면에 따로 표시한다.|시즌 이미지가 최신 설명과 달라 손님이 불편하면 직원에게 주문 전에 확인한다. 상품의 성분을 사진만 보고 판단하지 않는다.|실제 출고한 토핑은 메뉴 준비 기록과 사진을 확인한다. 이미지 교체를 했다는 사실로 구매 메뉴가 달라졌다고 답하지 않는다.
후식의 외부 제조 표시|외부에서 제조한 후식은 판매 화면에 포장 단위와 제조 표시를 안내한다. 필요한 원재료 정보는 제조사 성분표를 함께 본다.|후식이 매장에서 다른 소스와 합쳐진 경우 별도 토핑의 성분도 확인한다. 제조사 성분표만으로 최종 구성의 안전 여부를 판단하지 않는다.|개별 후식의 포장 정보는 로트 번호와 주문 기록을 대조한다. 현재 판매 중인 표기와 과거 판매 제품 기록을 구별한다.
식재료 보관 문의의 응답|구매 뒤 식재료를 보관할 때는 제품의 표시 안내를 따른다. 안내를 확인하기 어렵다면 주문 번호와 제품명을 직원에게 문의한다.|개봉 이후 보관 시간과 온도가 확인되지 않으면 공개 답글에서 섭취 가능성을 보장하지 않는다. 담당자가 확인이 필요한 항목을 따로 안내한다.|출고 당시 상태는 제품 제공 기록에서 확인한다. 고객이 실제로 보관한 조건은 매장 기록과 구별해 다룬다.
향신료 알레르기 신고 접수|향신료 관련 불편을 신고하려면 앱 문의에 주문 번호, 시각, 주문한 메뉴를 남긴다. 공개 리뷰에는 개인 건강 정보를 적지 않는다.|건강에 위급한 문제가 의심되면 현장 안내 절차를 적용한다. 직원은 신고 접수로 원재료 확인과 조사 완료를 대신하지 않는다.|확인 담당자는 원재료표와 주문의 조리 기록을 대조해 고객에게 안내한다. 담당자가 확인하기 전에는 특정 성분 또는 원인을 단정하지 않는다.

## 제27장 접근성과 시설
이동식 경사판 요청|출입구의 이동식 경사판이 필요하면 방문 30분 전까지 앱 접근성 문의에 방문 입구와 도착 시각을 남긴다. 직원은 배치 가능한 위치를 확인한다.|임시로 출입구가 막혀 있으면 안내 직원이 다른 접근 가능한 문을 먼저 알려 준다. 통행 경로와 경사판 배치는 함께 확인한다.|실제 경사판 설치 여부는 현장 담당자가 배치 완료 표시를 남겨야 확인한다. 예약 건의 요청 메모만으로 배치를 보장하지 않는다.
외부 전동 보조기기 충전 요청|외부 이동 보조기기의 충전이 필요하면 방문 전에 출력 규격과 예상 이용 시간을 접근성 문의에 적는다. 담당자는 사용할 수 있는 위치를 확인한다.|충전용 지정 장치가 없는 날에는 일반 테이블의 콘센트를 임의로 대신 쓰지 않는다. 다른 이용 공간을 직원이 안내할 수 있다.|충전 지원 완료는 지정 위치와 시작 시간을 기록한 담당자가 확인한다. 기기 충전이 실제로 끝났는지는 별도로 봐야 한다.
큰 글씨 메뉴 요청|큰 글씨 메뉴를 요청하면 카운터에서 그날 제공되는 음식을 큰 글씨 메뉴판으로 안내한다. 필요하면 직원이 옵션을 말로 읽어 준다.|사진이 제공되지 않는 한정 메뉴는 글씨 메뉴에 설명을 덧붙인다. 가격과 재료 조건을 확인한 뒤 주문한다.|실제로 요청한 큰 글씨 메뉴가 준비됐는지는 직원이 비치 상태를 확인한다. 지난 방문에서 제공했던 자료와 현재 수량을 구별한다.
휴대용 청취 보조 기기 대여|청취 보조 장치가 필요하면 방문 시 안내 데스크에서 대여 목록을 확인한다. 기기 번호와 반환 시각을 안내한다.|사용 중 말소리가 불분명하면 직원이 문자 안내를 제공한다. 파손 상태가 있는 기기는 소독 및 수리 전 대여하지 않는다.|기기 대여와 반납은 번호와 시간을 함께 기록한다. 예약 메모만 보고 실제 장비가 준비됐다고 답하지 않는다.
경사로 근처 좌석 확보|경사로 옆 통행이 필요한 손님은 예약 메모에 이동 공간을 요청할 수 있다. 매장은 테이블 사이 이동 가능 폭과 좌석을 확인한다.|경사로 출입을 막는 의자는 사용할 수 없다. 예약한 사람의 인원을 줄이지 않고 대체 테이블을 안내한다.|좌석 배정 여부는 직원이 번호와 공간을 확인한 다음 정한다. 요청자가 특정 번호를 적었다고 그 좌석이 확정되는 것은 아니다.
저소음 시간 지정 문의|저소음 시간은 주간 공지에서 안내한다. 통화나 큰 소리의 단체 활동은 별도 공간 이용을 안내한다.|정기 점검 방송이나 비상 상황은 저소음 운영 중에도 예외로 적용한다. 완전한 무소음 환경을 보장하지 않는다.|당일 운영 여부는 매장 공지와 현장 직원 기록으로 확인한다. 예전 주간 일정만으로 현재 소음 상태 또는 공석을 판단하지 않는다.
알레르기 자료 읽기 보조|재료표를 읽기 어려운 경우 직원에게 현재 메뉴의 표기 내용을 읽어 달라고 요청할 수 있다. 글씨와 재료 버전을 함께 확인한다.|조리 과정의 교차 접촉 여부까지 안내하려면 조리 담당자가 주문 조건을 확인한다. 읽어 준 정보는 안전 보장과 별도다.|안내가 제공된 건은 직원과 자료 버전을 기록한다. 고객 개인의 알레르기 안전 여부는 그 기록만으로 결정하지 않는다.
유모차 정리 보관|입구에서 유모차를 접어 맡기려면 안내 직원에게 예약 번호와 보관 예정 시간을 알려 준다. 지정 구역에만 보관한다.|통로를 막을 만큼 큰 물품은 정리 구역에 두기 어려울 수 있다. 배터리를 떼어 매장 내부에서 충전하지 않는다.|반납은 접수자가 맡긴 항목을 맞추어 확인한다. 입구에서 유모차가 보이지 않는 사실만으로 분실 또는 인계를 단정하지 않는다.
자동문 점검 안내|자동문 점검일에는 정문에 사용할 출입구와 점검 시간을 표시한다. 입구 바깥의 호출 버튼으로 직원 안내를 받을 수 있다.|정면 접근이 어려운 시간에는 별도 출입문으로 통행한다. 야외 진입 경로의 폭이나 경사를 현장 확인 없이 보장하지 않는다.|자동문 복구 시각은 시설 담당자가 작업 완료를 기록한 뒤 안내한다. 공지된 종료 예상 시각은 실제 복구 확인과 별도다.
보조견 동반 좌석 문의|보조견과 함께 방문할 경우 직원에게 테이블 주변 이동 공간이 필요한지 안내한다. 매장은 주변 통행에 맞는 좌석을 확인한다.|일반 반려동물 전용 테라스 규정을 보조견에게 자동 적용하지 않는다. 자세한 현장 안내는 접근성 담당자가 확인한다.|특정 좌석이 확정됐는지는 직원 배정 기록으로 확인한다. 방문을 문의했다는 사실만으로 현재 공석을 확정하지 않는다.
이용 시간 조정의 접근성 지원|이동 보조가 필요한 손님은 예약 전에 예상 이동 시간을 알려 이용 시작 시각 확인을 요청한다. 직원이 같은 예약의 적용 시간을 안내한다.|뒤 회차가 확정된 경우 사용 종료 시간을 보장해 늘릴 수 없다. 매장에서 다른 회차 선택을 도울 수 있다.|조정이 끝나면 예약 상세에 확정 시작·종료 시각이 함께 기록된다. 직원이 조정 가능성을 검토했다는 말과 구분한다.
화장실 통행 보조|무장애 화장실의 통행 안내가 필요하면 출입구 직원에게 잠금과 문 방향을 확인한다. 정기 점검 시간은 표지에 표시한다.|진입 경로에서 물건을 옮겨야 하면 손님이 옮기기 전에 직원이 확인한다. 청소 중에는 사용할 수 있는 다른 위치를 알린다.|현재 사용 가능 여부는 화면의 안내 시각과 시설 상태를 확인해야 한다. 일반 무장애 안내를 시설 점검 완료로 해석하지 않는다.
콘센트 자리의 전원 점검|콘센트가 필요한 손님은 예약할 때 기기 종류와 시간대를 적는다. 좌석의 콘센트 표시와 현재 이용 안내를 확인한다.|일시 점검 구역은 기존 콘센트 좌석이라도 전원 연결을 제공하지 않을 수 있다. 위험 징후가 있으면 사용을 정지한다.|전원 복구 여부는 시설 담당자가 점검 기록에 남긴다. 자리에 전원 표시가 보여도 실제 연결 가능 여부는 따로 확인한다.
다국어 현장 주문 안내|다국어 안내 자료가 필요하면 입구에서 원하는 언어와 주문 방식을 말한다. 제공할 수 있는 메뉴 요약과 결제 안내를 보여 준다.|원재료 문의는 해당 버전의 성분표를 기준으로 안내한다. 번역 자료의 알레르기 표기는 직원이 한 번 더 확인한다.|어떤 언어 자료가 실제 제공됐는지는 직원의 안내 기록을 확인한다. 안내 언어 선택과 메뉴 선택 과정의 완료를 구별한다.
안내 의자 단기 사용|입구의 안내 의자는 대기 번호가 있는 사람 가운데 휴식이 필요한 손님이 잠시 사용할 수 있다. 직원에게 현재 사용 가능한 의자를 확인한다.|통로를 막는 자리로 의자를 옮기지 않는다. 지정 구역이 찼으면 매장에서 다른 대기 위치를 안내한다.|실제 의자 설치나 확보는 입구 담당자가 확인한다. 의자 개수 표기만으로 특정 시간에 사용 가능하다고 답하지 않는다.

## 제28장 단체 행사와 제휴
단체 행사 안내 문자 수신처|단체 예약의 행사 문자 수신처는 예약 대표가 방문 전날 오후 5시까지 지정한다. 새 수신처와 변경 시간을 앱 상세에 표시한다.|이미 문자 발송이 끝난 경우에는 다음 알림부터 새 수신처를 적용한다. 제삼자가 번호를 바꾸려면 대표 권한을 확인한다.|실제 수신 여부는 발송 기록과 수신 기기 상태를 확인한다. 대표의 선택이 바뀐 사실만으로 모든 문자가 새 번호에 갔다고 말하지 않는다.
소규모 시식 행사의 메뉴 변경|예약된 시식 행사의 메뉴 변경은 행사 이틀 전까지 대표가 행사 문의 창에서 요청한다. 선택 가능한 메뉴마다 기본 제공량을 확인한다.|일반 매장 주문의 대체 메뉴를 시식에 자동 적용하지 않는다. 식재료 기준이 다른 메뉴는 준비 가능 여부부터 확인한다.|새 시식 메뉴는 구성표에 확정 표시가 된 뒤 알린다. 대표가 변경 사유를 보낸 것만으로 승인 완료를 안내하지 않는다.
기업 식사권의 대표 정산|기업 식사권 계약은 정산 담당자가 기간과 대상 주문을 정해 월말에 정산한다. 지점별 내역을 대표 계정의 명세서에 표시한다.|개인 계정 주문은 단체 청구에 자동 포함하지 않는다. 착오가 있다면 정산 담당자에게 원래 주문 번호를 확인한다.|정산이 끝났는지 묻는 건은 명세서와 결제 대장에 완료 기록이 있는지 대조한다. 예약 목록만으로 청구 여부를 판단하지 않는다.
제휴 리워드 지급 조건|제휴 리워드는 주문 전에 제휴 페이지에서 할인 대상 메뉴와 행사 시각을 확인한 뒤 적용한다. 결제 화면에 현재 적용한 혜택을 보여 준다.|장바구니에 할인 제외 품목이 들어 있어도 제외 여부를 항목별로 알린다. 오지 일반 구매 포인트 규정을 그대로 적용하지 않는다.|지급이 끝났는지는 제휴사 리워드 기록과 주문 승인 번호를 맞추어 확인한다. 참가 안내를 읽었다고 실제 지급됐다고 답하지 않는다.
단체 명찰 출력 요청|명찰이 필요한 행사는 행사 전날 15시까지 별칭과 장수를 담당자에게 제출한다. 행사 대표가 제출 목록을 확인한다.|회사 내부 정보나 개인 연락처를 명찰에 넣으려면 행사 담당자가 사용 범위를 확인한다. 날짜가 다른 행사에는 명단을 자동 복사하지 않는다.|실제 출력 완료 여부는 인쇄 장수와 행사별 명단을 확인한 뒤 안내한다. 명단 접수는 현장 비치 완료와 구별한다.
행사 레이아웃의 현장 변경|공간 레이아웃 변경은 행사 시작 60분 전까지 행사 대표가 직원에게 접수한다. 통로 폭과 예약 인원을 확인한 뒤 테이블을 배치한다.|출입문 앞과 비상 통로에 좌석을 둘 수 없다. 필요한 경우 직원이 좌석 수를 제공 범위 안에서 조정한다.|설치 완료는 배치도와 실제 테이블 위치를 담당자가 확인할 때 기록한다. 요청서가 제출됐다고 변경 결과를 확정하지 않는다.
같은 지점의 행사 연속 예약|같은 방을 연속 회차로 잡으려면 회차 종료와 다음 회차 시작 사이에 정리 시간을 포함한다. 시간표는 회차별로 발급한다.|한 회차 결제 완료를 다른 회차 예약 승인으로 처리하지 않는다. 대표가 회차별 예약 번호를 확인해야 한다.|전 회차가 확정됐는지는 각 번호의 확정 시각을 확인한다. 한 회차의 초대 링크가 전 행사에 적용되는지 추정하지 않는다.
학교 동아리 행사 대표 변경|학교 단체 행사 대표를 변경하려면 기존 담당자가 행사 이틀 전까지 대표 변경 양식을 제출한다. 학교 측 승인 연락을 받은 후 갱신한다.|이미 행사비 정산이 시작된 건은 기존 계약자의 수납 정보를 먼저 확인한다. 개인 방문 예약으로 대표를 교체할 수 없다.|변경이 적용되면 행사 관리 화면에 새 대표와 승인 시각이 나타난다. 단순 명단 수정만으로 대표 교체를 확정하지 않는다.
외부 케이크의 냉장 보관|외부에서 가져온 케이크는 행사 전에 보관 규격과 들어오는 시각을 직원에게 알린다. 제한된 냉장 공간을 확인한 뒤 안내한다.|이미 개봉하거나 운반 온도를 확인할 수 없는 케이크의 상태는 매장이 보장하지 않는다. 냉장 공간을 쓸 수 없는 날에는 대안을 안내한다.|실제 케이크 입고는 담당자가 보관 표에 시간과 위치를 적은 뒤 확인한다. 예약 요청에 케이크가 적혀 있어도 보관 여부는 별도다.
단체 전용 음료의 미사용 반환|예약에 포함한 단체 음료를 일부 쓰지 않으면 제공 내역을 직원과 확인한다. 미개봉 보관 여부와 계약 항목을 기준으로 반환 절차를 안내한다.|이미 나누어 담은 음료와 미개봉 제품은 같은 방식으로 반환하지 않는다. 단체 행사 종류별 조건을 확인한다.|차감 또는 반환 완료는 행사 종료 명세서와 음료 사용량 기록으로 판단한다. 미사용 의사를 말했다고 처리 완료를 단정하지 않는다.
합동 제휴 행사의 할인 중첩|두 제휴가 함께 진행되는 행사는 쿠폰 상세에 중첩 가능 여부를 표시한다. 중첩이 허용된 항목의 할인 순서를 결제 전 보여 준다.|같은 혜택이 중복 발급된 경우 기존 할인과 새 할인을 모두 지급하지 않는다. 제휴 정보가 다르면 행사 문의에서 확인한다.|할인이 실제로 들어갔는지는 주문 영수증의 혜택 항목을 대조한다. 광고의 중첩 안내와 개별 구매의 적용 여부는 따로 확인한다.
후원자와 일반 참가자 접수|후원자 배정 회차의 좌석은 초대장을 받은 계정에서만 신청할 수 있다. 남는 자리는 사전에 안내한 시간부터 일반 접수를 받는다.|지인 명의 초대장을 받은 사람은 행사 담당자가 이전을 확인해야 같은 범위에서 신청할 수 있다. 발송 메일만으로 대신 좌석을 잡지 않는다.|일반 공개 전환이 실제 시작됐는지는 이벤트 관리 화면의 접수 상태와 시각을 대조한다. 예정 시간 자체를 예약 성공으로 안내하지 않는다.
행사 사진 수령 신청|행사 사진 제공 대상자는 담당자가 알린 행사 코드로 촬영 동의 범위를 확인하고 신청한다. 발송 시각까지 확인할 수 있는 내역을 남긴다.|촬영 동의하지 않은 사람의 사진은 일반 요청으로 발송하지 않는다. 신청자가 공유 범위 조정을 원하면 담당자가 확인한다.|실제 사진 전달 여부는 올바른 행사 코드와 발송 기록 및 수신 상태를 확인한다. 파일 목록이 만들어졌다고 발송까지 됐다고 답하지 않는다.
제휴 예약의 주문번호 매칭|제휴로 예약한 손님은 방문 시 제휴 번호와 매장 주문 번호를 직원에게 보여 줄 수 있다. 지원하는 행사에만 번호 매칭을 제공한다.|실제 매장 결제를 하지 않은 예약은 정산 기준이 다를 수 있다. 매장 주문이 같은 이름이라는 이유로 예약과 자동 연결하지 않는다.|두 번호가 연결됐는지 담당자는 예약 슬롯과 주문 승인 시각을 함께 확인한다. 매칭 요청이 알림에 도착한 것과 완료 여부를 구분한다.
단체 대표의 증빙 공개 범위|단체 대표는 참석 인원과 금액이 적힌 단체 명세를 계약 담당자에게 요청할 수 있다. 공개 범위는 계약에 따라 표시한다.|참가자별 결제 개인 정보는 단체 명세에 그대로 포함하지 않는다. 개인 영수증은 당사자가 따로 확인한다.|명세가 실제 발급됐는지는 문서 번호와 전송 시간이 있는지 확인한다. 신청자에게 발급 예정이라고 알린 사실과 발행 완료는 별도다.

## 제29장 분실물과 기록 문의
보관 만료 지난 분실물 문의|분실물은 물건 종류와 발견 시각을 알려 앱 분실 문의에서 찾는다. 보관 기한은 발견 기록과 문의 답변에 표시한다.|기한이 지난 물건의 반출·폐기 여부는 담당자가 보관 내역을 확인한다. 제삼자의 이름이 적힌 물건을 공개 채널에 올리지 않는다.|실물 보관 여부는 담당자가 식별 정보와 현장 재고를 대조해야 답할 수 있다. 문의 등록으로 물품이 남아 있다고 단정하지 않는다.
휴대전화 분실 잠금 화면 확인|휴대전화 분실 문의는 방문 시간, 기기 색과 케이스 구분을 앱 문의에 적는다. 기기 비밀번호를 요구하지 않는다.|다른 고객의 휴대전화를 가져가지 않도록 카운터에서 잠금 화면 외형과 접수 정보를 대조한다. 소유자가 불분명하면 인계를 보류한다.|인계 완료는 찾은 물건의 접수 번호와 인계 기록이 일치할 때 확인한다. 담당자가 물건을 찾을 수 있다고 말했다는 이유로 인계를 확정하지 않는다.
동일 색상의 우산 착오 교환|우산이 바뀌었으면 주문이나 방문 시각과 우산 표식을 앱 분실 문의로 알린다. 다른 고객 소유와 비교할 정보를 따로 확인한다.|우산의 색만 같은 경우에는 바로 교환하지 않는다. 접수된 물건의 사진을 공개 후기에서 재전송하지 않는다.|교환 여부는 보관 번호와 수령 확인을 대조해 판단한다. 우산이 비슷하다는 말로 실제 분실품이 매장에 있다고 확정하지 않는다.
법인 소지품의 인계 확인|회사 소지품을 찾으려면 예약 대표나 소유 부서의 물건 식별 정보를 앱 문의로 확인한다. 대표자가 담당자를 지정할 수 있다.|개인의 지갑과 달리 회사 소지품은 인계 명의가 달라질 수 있다. 공개 답글에 내부 표식과 번호를 올리지 않는다.|인계 완료 확인은 보관 대장과 수령 자격 확인을 함께 본다. 대표가 찾는다고 연락한 것만으로 이미 전달됐다고 답하지 않는다.
냉장 보관 중 분실 식품 조치|매장에서 남은 포장 음식을 발견하면 현장 처리 규정에 따라 발견 장소와 시각을 기록한다. 냉장 보관 여부는 담당자가 확인한다.|개봉된 음식과 포장 상태가 유지된 음식은 보관 방법을 구분한다. 실제 먹어도 된다고 공개 답글에서 보장하지 않는다.|현재 음식 보관 상태는 직원이 사용 기록과 현장 상태를 확인해야 알 수 있다. 과거 방문 기록만으로 수령 가능 여부를 안내하지 않는다.
문의 답변 수신 날짜 변경|앱 문의 답변의 예상 날짜는 담당자가 사유와 함께 조정할 수 있다. 알림에 표시된 예상일과 접수일을 각각 보여 준다.|대기 중 날짜가 지나도 문의가 자동으로 종료되지는 않는다. 먼저 처리된 긴급 문의와 개별 답변을 구분한다.|문의가 실제 답변됐는지는 답변 본문과 저장 시각으로 확인한다. 알림을 한 번 받았다는 사실로 답변 여부를 확정하지 않는다.
앱 첨부 영상 제한|문의에 동영상을 넣으려면 지정 형식과 20메가바이트 제한을 확인한다. 문의 범위에 맞는 부분만 잘라서 첨부할 수 있다.|다른 고객 얼굴이나 주문번호가 영상에 들어 있으면 가린 사본을 제출한다. 전체 영상에 접근 권한이 필요하면 담당자가 안내한다.|파일이 정상 접수됐는지는 문의에 첨부 표시와 업로드 시각이 있어야 확인한다. 전송 누름 후 보이는 파일 선택 화면으로 성공을 판단하지 않는다.
오래된 주문의 처리 이력 열람|주문이 오래돼 앱 목록에서 사라지면 원 주문 번호와 결제 시각을 앱 문의에 남긴다. 담당자가 기록 보존 기간과 조회할 수 있는 범위를 확인한다.|보존 기간이 지난 기록은 항상 복구할 수 있는 것으로 약속하지 않는다. 타인 주문의 처리 기록에 대한 공개 답변도 제공하지 않는다.|실제 기록이 조회됐는지는 담당자가 해당 주문과 조회 결과를 확인한 뒤 안내한다. 다른 주문의 유사 금액은 대신 쓰지 않는다.
메일 답변과 앱 문의 연동|동일 문의에 메일 답변이 필요하면 앱 문의 화면에 답변 수신 경로를 선택한다. 매장 안내는 한 문의 번호로 관리한다.|메일을 바꿔도 기존 문의 이력을 넘어 가져오지 않는다. 주문 정보가 포함된 답변은 등록한 회신처에서만 확인한다.|두 경로의 답변이 일치하는지는 문의 번호와 발송 시각을 비교한다. 메일 주소 갱신만으로 이전 메일의 수신을 확인하지 않는다.
관련 사건의 리뷰 수정 요청|후기를 수정하고 싶으면 작성자가 앱 리뷰 메뉴에서 편집을 연 뒤 저장한다. 매장은 수정 여부를 강요하지 않는다.|직원이 사실관계 문구의 정정을 안내하더라도 포인트나 환불 조건을 후기 수정에 묶지 않는다. 관련 문의는 별도로 처리한다.|수정이 반영됐는지는 리뷰 버전과 공개 시각을 확인한다. 댓글에 수정하겠다고 말한 사실만으로 편집 완료를 판단하지 않는다.
일반 시설 문의를 안전 담당자에게 전달|시설 결함을 발견하면 안내 직원에게 장소와 발견 시각을 알린다. 담당자는 우회 동선을 안내하고 시설 확인 요청을 접수한다.|사용 중인 구역에서 위험이 의심되면 현장 지침에 따라 출입을 안내한다. 발견자가 직접 시설을 고치도록 요청하지 않는다.|시설 이상이 해결됐는지는 담당자가 점검 후 완료를 기록해야 한다. 접수 알림만으로 안전 상태를 단정하지 않는다.
행사 분실품의 방문 예약 수령|보관 중인 행사 분실물을 찾으려면 행사 코드와 방문 예정 시간을 담당자에게 알린다. 일반 분실품의 식별 확인도 함께 진행한다.|행사 시간 바깥에 찾아올 경우 보관 담당자가 근무 중인지 확인한 뒤 새 시간대를 제시한다. 보관 기한을 행사 날짜로 갱신하지 않는다.|실제 수령은 보관 대장의 수령 확인과 인계 시각을 보고 판단한다. 방문 예약이 접수됐어도 수령을 완료했다고 답하지 않는다.
증빙 없는 예전 문의 되살리기|상담 내용을 이어가려면 원래 문의 번호나 발생 날짜와 지점을 알린다. 해당 정보로 문의 표제와 연결 상태를 찾는다.|문의 번호가 없고 여러 기록이 맞으면 신원과 주문 정보를 추가로 확인한다. 일반 안내로 실제 처리 결과를 대체하지 않는다.|이전 문의가 실제로 연결됐는지는 새 문의 내 연결 표시와 담당자 기록을 확인한다. 같은 제목이 있다는 이유만으로 조회했다고 답하지 않는다.
상담 중단 후 재개 신청|이미 닫힌 상담을 다시 열고 싶으면 종료일 5일 안에 같은 번호로 후속 질문을 입력한다. 담당자가 이전 주제와 같은지 확인한다.|별개 주문 문제라면 새 문의를 만들고 원래 번호를 참고로 적는다. 오래된 상담의 첨부 파일이 항상 다시 열리는 것은 아니다.|재개 여부는 상담 상태가 열린 상태로 표시되고 담당자 배정 시간이 남았을 때 확인한다. 새 질문을 보냈다는 사실로 완료를 단정하지 않는다.
직원 칭찬 전달 요청|직원의 응대를 칭찬하고 싶으면 방문 시간과 안내받은 위치를 앱 칭찬 메뉴에 남길 수 있다. 실명이나 연락처 없이 전달한다.|분실물·환불처럼 확인이 필요한 내용이 섞이면 고객 요청을 분리해 담당 부서에 전달한다. 일반 칭찬에 답할 때 처리 상태를 답하지 않는다.|실제로 어느 직원에게 전달됐는지는 담당자가 내부 전달 기록을 확인한다. 공개 답글에서 특정 직원이 이미 읽었다고 약속하지 않는다.
