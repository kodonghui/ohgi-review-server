## 라우터가 확인하는 것

1. [`route_questions()`](../../app/services/policy_topics.py)는 일반 후기, 등록된 규정 문의, 문서 검색이 필요한 질문, 매장 확인이 필요한 요청을 구분합니다. 기존 등록 주제가 질문의 초점을 덮지 못하면 그 질문을 문서 검색에 넘깁니다. 같은 주제를 두 번 감지했을 때도 두 번째 질문을 남깁니다.
2. [`PolicySearch.retrieve()`](../../app/services/policy_search.py)는 오배송·파손처럼 정해진 조문은 ID로 읽습니다. 다른 문의는 하이브리드 후보를 보존하고, 필요한 근거가 없을 때 해당 하위 질문만 한 번 다시 검색합니다.
3. [`PolicyPassages.select()`](../../app/services/policy_passages.py)는 원문 제목과 문장을 봅니다. 수량에는 단위가 붙은 수량, 마감에는 기한을 요구합니다. 여러 정책에 공통으로 등장하는 대리 수령·문의는 조문에서 적용 대상을 확인한 뒤 해당 행동을 설명하는 문장을 고릅니다. 가능 여부나 절차를 물으면 조건을 담은 문장까지 확인합니다. 일치하는 후보가 없거나 점수가 비슷하면 보류합니다. 한국어 표현을 정규화하며 새 조문 번호를 등록할 필요는 없습니다.
4. 문서 검색으로 고른 조문은 필요한 구절을 답글 작성·검토 프롬프트에 넘깁니다. 네 가지가 섞인 요청을 처리하기 위해 최대 조문 수를 3개에서 6개로 조정했습니다. 기존 사건별 필수 문구와 저장 전 검토는 그대로 적용합니다.

### 실행 사례

- **S01 승강기** · “휠체어 타고 지하 주차장에서 올라가려면 어느 구역 승강기를 타야 해요?”에 기준 버전은 제4조 주차 규정을 저장했습니다. 최종 버전은 제36조의 **A구역 승강기**를 답글에 넣었습니다.
- **S24 네 조문** · 유아 의자, 예약 지연, 주류, 배달 마감을 묻는 질문에 제37·49·18·15조와 각 핵심 구절을 저장했습니다. 하이브리드에 원질문만 넣으면 네 조문이 모두 후보에 들어오지 않았습니다.
- **S27·28·30·31** · 실제 환불 입금, 차량 주차 지원 등록, 관리자 암호, 분실물 습득 여부는 모두 보류했습니다.
- **루프백 HTTP** · Uvicorn에서 승강기와 유아 의자 문의의 SSE 최종 응답과 수정, 주문번호를 제시하지 않은 포장 대리 수령 조건 안내, 분실물 대리 수령의 별도 조문, 실제 수령 여부 보류를 확인했습니다. [HTTP 응답 원본](results/155-5993846-localhost.json)

### 측정값의 범위

고정 문항과 두 진단 세트는 개발에 사용한 회귀 평가입니다. 구절 검사와 가짜 모델은 검색·검토·저장 연결을 확인합니다. 실제 OpenAI 호출은 0회이며 실제 답글의 자연스러움, 새 표현 전체에 대한 정확도, 모델 비용은 별도 평가가 필요합니다. 요청 지연은 한 PC에서 순차 측정한 값으로 실행 당시의 부하에 영향을 받습니다.

## 재현

[이전 규정집 생성 명령](RESULTS.md#실행-기록과-재현)으로 같은 Markdown을 만든 뒤 제품 루트에서 실행합니다.

```powershell
$book = '.local/benchmark/regulations-50p.md'
$version = 'c6f0fb0'
uv run --locked python benchmark/scale/run.py --expanded-only --source-commit $version --markdown $book --output ".local/benchmark/155-$version.json"
uv run --locked python benchmark/scale/run.py --diagnostics-only --source-commit $version --markdown $book --output ".local/benchmark/155-$version-diagnostic.json"
uv run --locked python benchmark/scale/run.py --diagnostic-file benchmark/scale/policy-scope.json --source-commit $version --markdown $book --output ".local/benchmark/155-$version-scope.json"
uv run --locked python benchmark/scale/smoke.py --expect-policy-scope --source-commit $version --markdown $book --output ".local/benchmark/155-$version-localhost.json"
```

앞 버전의 16문항을 다시 실행하려면 `--diagnostic-file` 명령의 `$version`을 `2695f60`로 바꿉니다.
