### 문항과 실제 결과

[실행] M01은 공휴일이 아닌 금요일 오후 4시 매장 식사와 전화 포장을 묻습니다. 기대값은 제1조와 제6조, 매장 식사 불가와 앱·홈페이지 포장 안내입니다. H01은 특정 고객의 적립 완료를 묻고, 기대 상태는 직원 확인입니다.

[실행] 교재 k=3에서 M01의 Chroma 검색 순서는 제1조, 제221조, 제465조입니다. 이 순서에서는 영업시간을 확인할 수 있고 전화 포장에 필요한 별도 조문은 빠졌습니다. 전체 API의 조문 최종 선택과 저장 결과는 아래 요청별 트레이스에서 확인합니다.

## 재현 자료와 한계

- 공통 LangSmith 데이터셋의 문항 ID로 검색과 답글 트레이스를 대조합니다.
- 200페이지 생성기는 `benchmark/scale/render_200.py`에, 두 검색 저장소는 `benchmark/scale/index_200.py`에, 실행과 채점은 `benchmark/scale/eval_200.py`에 있습니다. 답글 API 데이터는 `data/langsmith_reply_golden_200_v1.json`입니다.
